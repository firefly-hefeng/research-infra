## 4. 三机 GPU 用户与任务监控

固定只读探针已部署到 47、101、139 三台服务器，探针 SHA-256：

`d92959204b55dd9b54665ee10c43c6a498e076ca2c39ca66adf202f6ca47447e`

每张 GPU 卡片可展开查看：

- Unix 用户；
- 脱敏任务名（仅白名单参数值或脚本/目录 basename）；
- PID 与进程 basename；
- 进程显存；
- GPU 利用率、温度、总显存与已用显存。

探针不返回完整命令行、工作路径、环境变量、训练日志或数据集内容，不会自动停止任务或重置 GPU。旧快照没有进程字段时继续兼容显示。出现“0 MiB 显存但利用率高且无已登记计算进程”时，仅提示异常，不自动判定硬件故障。

## 5. GPU4 事件处理记录

2026-10-29，服务器 47 的 GPU4 曾出现 0 MiB 显存、100% 利用率且无已登记计算进程的异常。单卡重置最初被其他训练进程持有的设备句柄阻止。

在明确授权后，先终止占用进程，再执行 `nvidia-smi --gpu-reset -i 4`，重置成功。新任务随后正常投递，未观察到新的 Xid 错误。此次操作只针对 GPU4，没有重启整台服务器。
