# 科研数据与成果整理 Agent 议会工作规范

专题历史记录。日常协作与当前接入从 [Agent 手册](../research-data-center-next/docs/agent-guide.md)开始；本文不是所有 Agent 的必经操作流程。

## 目标

以同一套“疾病/研究领域＋资源角色”分类组织成果进展中心、数据管理中心和 `/data/share/public` 投递项目。议会只生成可审核的建议和回执，不自主移动、删除、发布或覆盖数据。

## 分类维度

- 疾病/研究领域：抑郁与情绪、认知障碍、帕金森与运动障碍、病理言语/嗓音、呼吸/咳嗽/睡眠、心音/循环、儿童语言与发育、通用语音/多语/情绪、跨疾病、待确认。
- 资源角色：原始数据、派生数据、特征、模型、评测、代码/工件。
- 疾病类别不能替代任务类别；模型名称不能反推数据已入库；没有证据的类别保持为空或待确认。

## 角色与职责

| 角色 | 主要工作 | 必须输出 | 禁止事项 |
|---|---|---|---|
| 分类编辑 | 阅读名称、README、官方资料，提出疾病与任务分类 | 每项类别、依据、置信度、未知项 | 仅凭目录名猜疾病或临床标签 |
| 证据审核 | 核对指标、数量、许可、版本、验证范围 | 指标口径、证据路径、待补说明 | 把开发集写成测试集、把合作写成临床验证 |
| 数据管家 | 检查 public 内容角色、权限、占用和目标路径 | move/defer 建议、目标路径、兼容方案 | 移动运行中项目、复制大文件、删除源数据 |
| 界面编辑 | 审核多级导航、空状态、移动端与可访问性 | 页面与交互验收结果 | 隐藏验证边界、用装饰数字替代证据 |
| 发布复核 | 对照迁移回执、平台 catalog 和飞书表格 | 发布清单、差异、未决项 | 无回执宣称完成、覆盖历史身份或数量 |

## 标准流程

1. **只读盘点**：保留源路径、权限、内容角色、数量单位和运行占用。
2. **独立审核**：分类编辑与证据审核分别给出建议，不用同一份未经复核的猜测直接发布。
3. **生成候选清单**：目标路径、move/defer、兼容软链、回执字段和待补说明齐全。
4. **授权执行**：仅处理已审核项目；同文件系统优先移动，保留原路径兼容软链。
5. **交叉核验**：目标存在性、兼容链接、catalog、资料卡、飞书记录逐项一致。
6. **发布与复查**：平台、飞书和部署说明一致，未迁移与待确认项明确保留。

## 当前成果分类

- 抑郁与情绪：DepAlign、MMPsy v3、Daily Text Risk。
- 情绪与副语言：中文声音表达融合头 v2。
- 跨疾病：通用疾病声音 Encoder。
- 合作机构、内测和传播数据单列，不按疾病归因。

## public 初审原则

- depression 项目：抑郁与情绪；按模型或数据内容细分。
- AD 项目：认知障碍；按模型/数据/实验工件细分。
- rms-aqa：通用音频理解与空间交互。
- midasheng：在正式资料核实前保持待确认，不猜疾病。
- 代码、日志、评测、运行目录不自动等于模型或数据集；运行中项目延期，私有目录由 root 审核。

## 发布约束

- 不写密码、访问令牌或私有诊断到清单、文档或公开导出。
- 不覆盖原 228 条登记身份；新迁移资源独立登记。
- 不把代码行数、日志数、重复版本数当作独立数据集或参与者数量。
- 飞书更新保留历史记录，重复项只更新不新增；表格与迁移回执不一致时停止发布。
