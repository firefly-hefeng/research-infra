# 科研管理平台使用与维护说明

[仓库 README](../README.md) · [科研工作台](https://rmp.wuwangwo.top/) · [本地开发](../dev/README.md)

## 成员的使用入口

| 模块 | 日常使用 | 核对依据 |
| --- | --- | --- |
| 数据与模型 | 按研究标签、研究大类和细分类找数据或模型，资料卡可进入飞书原记录。[数据与模型](https://rmp.wuwangwo.top/#data-platform) | 飞书原记录登记位置、许可和核验时间。门户为浏览入口，数量与可读性以对应版本的核验记录为准。 |
| 团队进展 | 先读团队概览，再按成员和日期、周次查日报与周报。[团队进展](https://rmp.wuwangwo.top/progress/#team) | 依据署名报告、实验记录和原件。日报先选日期与成员，周报先选周次。文件格式、附件和大小限制以生产页面为准。 |
| 方向与方法 | 按研究问题查已尝试的方法、对照、结果和联系人。[方向与方法](https://rmp.wuwangwo.top/progress/direction-methods) | 同题、同评测条件下才排列效果。建议负责人、项目联系人与正式负责人分别标注，方便成员复核。 |
| 文献 | 按题录、分类和主题发现文献，从导读回查原文。[文献库](https://rmp.wuwangwo.top/papers/) | 作者关键词与整理标签有各自字段。引文可回查 PDF 页，摘要、全文和局部阅读的证据范围分别标注。 |
| 原点文档与算力 | 查研究路线、周会或共享文书，查看已保存的服务器和 GPU 观察记录。[原点文档](https://rmp.wuwangwo.top/#documents) · [服务器资源](https://rmp.wuwangwo.top/servers) | 飞书正文和附件沿用成员的原件权限；算力信息查看观察时间、覆盖窗口和缺测。 |

## Agent 如何接手

用自己的飞书成员会话进入工作台的 [Agent 入口](https://rmp.wuwangwo.top/#agent)。先用团队进展或思路对应的目录找稳定 ID，再展开原报告、方法对照、数据版本和论文。把来源、日期和实验口径一起保留。

仓库当前提供[本地只读科研进度 MCP](../research-data-center-next/docs/progress-mcp.md)。客户端按需启动，默认通过本机已经登录的平台标签页查询。依次可读团队概况、成员进展、登记方向和方向方法。已有成员导出也可离线读取，日期和缺失材料以导出结果为准。

方向文档保留研究问题、联系人、最近证据和下一步。研究报告写清完成事项、结果与证据、问题与阻塞和下一步。实验记录放在对应项目，至少保存输入版本和划分、代码或配置、评估方法、产物链接与局限。整理成果时沿用已登记 ID，标明成员原话与自动生成建议的来源。

## 数据存放与台账

正式共享资料从 `/data/share/datasets` 和 `/data/share/models` 查找。新增交付沿用 [入库指南](../research-data-center-next/docs/incoming-guide.html)。查库时同时核对发布版本、使用条件和当前主机的读取权限。

冷盘使用 `/data/share_cold`。归档完成后记录物理位置、兼容入口、文件范围和校验日期，更新飞书字段「存放位置或领取入口」与「依据及更新时间」。源卷释放空间、冷盘新增对象大小和科研样本量分别记录。[冷盘迁移与台账步骤](../research-data-center-next/docs/storage-catalog-workflow.md#7-冷盘迁移与飞书台账)

## 运行和更新

| 环境 | 运行方式 |
| --- | --- |
| 生产 | 统一 HTTPS 入口转发至独立的门户、进度及论文服务。进度和管理入口使用飞书统一登录。实际服务路径、配置和材料以运维部署及当前访问权限为准。 |
| 本地 | [联调启动器](../dev/README.md)提供 `127.0.0.1:18081` 入口，门户、进度和文献分别监听 `8765`、`8766`、`4186`。演示数据和日志保存在 `.local-dev/`。 |
| 独立模块 | 按[资源](../research-data-center-next/README.md)、[进度](../research-progress-next/README.md)、[文献](../paper-library-next/README.md)各自的 README 启动。检查接口、端口和数据根后再组合部署。 |

运行中的 SQLite、队列和锁使用对应服务的本机目录。可以独立发布某个模块。发布前检查本轮差异、现有数据入口和回退版本，发布后用实际账号验证正常读取、空结果和访问边界。涉及界面的改动检查桌面和手机。历史命令、数据范围和配置从[部署归档](科研平台部署说明_20261029.md)按日期回查。

本说明记录入口及维护约定。规模、进度与容量在各业务系统中持续更新，引用时使用当前来源的观察时间。
