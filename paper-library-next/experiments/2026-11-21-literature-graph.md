# 从研究方向找到有据可查的关联论文

2026-11-21。本次验证对象为文献模块、已有导入清单及待发布文件。目标是让成员和 Agent 能用同一条依据回答“为什么这篇论文出现在这里”，并从图中回到原有论文详情。

## 来源与设计取舍

- 在本机 VESTI-APP 的 `676eece` 阅读 `packages/vesti-ui/src/tabs/network/sphere-layout.ts` 与 `TemporalGraph.tsx`。采用确定性的球面分组、组内散布、相机旋转、选中高亮和标签避让。列表承载完整题名、来源和所有邻居，也可独立用键盘操作。

## 复核

服务端适用 `python3 -m unittest discover -s tests -v`。交互可信的最短路径为“文献图谱 → 方向 → 论文 → 署名 → 另一篇论文 → 打开论文详情”。图中显示的论文按分组抽样；右侧或手机下方的邻居列表可展开全部。部署后的计数须从现网重新读取，导读的实时状态可能与上述导入清单不同。发布与回退由平台统一执行。
