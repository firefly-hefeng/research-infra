# 文献发现、阅读与原件权限合并验证

**日期** 2026-11-21。**范围** 科研平台的独立文献模块。本次使用临时论文库、本机服务及浏览器进行工程验收。

## 来源和合并

上游为 `firefly-hefeng/research-infra` 的 `63fd179f704ce2f924d532052cac40e7aeab9c7a`。本项目合并前的分支基线为 `9f5a951`，工作区有五个已修改文件，另有既有模块说明和运行目录。逐文件对照上游和本地版本，保留本地的 DOI 规范化、读取失败重试、草稿与登录恢复、平台导航和原件权限。导读、作者关键词、主题标签、已读范围及原文页码沿用上游的内容校验。[上游版本](https://github.com/firefly-hefeng/research-infra/tree/63fd179f704ce2f924d532052cac40e7aeab9c7a/paper-library-next)

阅读详情新增「相关阅读」。仅对比已收录题录和卡片的关键词、主题标签，逐条列出共同词；没有交集时不会出现该栏目。目录及逐篇读取使用同一套 SQLite 联表查询。档案、题录和导读以论文 SHA-256 关联，避免每次刷新逐条重新连接查库。

## 验证方法和实测结果

| 范围 | 方法及结果 |
| --- | --- |
| 原版对照 | 上游原版的 Python 套件通过 110 项。复核发现原版产品约定允许匿名获取已存储 PDF，并允许下载历史标记受限的 PDF。该行为与本平台已有许可约定冲突。 |
| 本项目接口 | 合并后 Python 套件通过 110 项。启用登录验证时匿名取目录或 PDF 返回 401；登录后取受限 PDF 及 Range 均为 403；可读 PDF 的 Range 返回 206；缺失 PDF 返回 404。只读目录经过字段筛选，管理 API 沿用原认证。 |
| 前端逻辑 | 题录回归 48 项断言、发现和管理交互 364 项断言、实际页面节点契约 116 项断言通过。包含完整 DOI 链接、空结果、网络失败与重试、登录恢复、收藏、草稿和相关阅读。 |
| Chromium 端到端 | 1440、390、320 像素三个视口。合成题录覆盖 3 个方向，每个视口均通过登录、推荐页、DOI 搜索、受限题录、按共同词跳转、可读 PDF Range 及管理页笔记保存重读。页面无横向溢出或脚本错误，保留截图摘要。 |
| 研究数据影响 | 验收专用 PDF、SQLite、测试账户和笔记位于临时环境。未启动模型整理，未写入线上笔记、论文或数据库。 |

本机逐文件备份目录为 `%TEMP%/rmp-paper-merge-wks6kecy`。`before.json` 记录原文件摘要，`before/` 保留原字节；原始值为 null 的文件为本次新增。恢复前需先与本次合并后的摘要对照，保留后续编辑。每个变更文件的前后摘要及浏览器结果见[验收证据](evidence/2026-11-21-literature-merge.json)。发布时仍需核对现网反向代理、运行版本和原件访问范围。

## 正式部署与成员阅读

11 月 21 日再次读取 GitHub HEAD，仍为上文的 `63fd179`。已基于 101 的实际运行版本部署后端 3 个文件及两个现有静态发布目录各 3 个文件。正常重启文献服务后，目录接口返回 200。飞书成员实测桌面 1440 像素与手机 390 像素的目录检索、发现、题录详情和管理入口。336 条题录中的全文权限在这次成员会话均为受限。实际检索 DOI 并打开详情后能阅读题录、前往来源，按 Esc 可关闭详情。已获许可的 PDF 范围读取在前述合成库验收。[生产回执](../../research-data-center-next/experiments/evidence/2026-11-21-production-delivery.json)
