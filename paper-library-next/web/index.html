添加与整理论文

01

放入待整理区

在服务器上将 PDF 复制到下方目录，完成复制后点击“扫描新文件”。

02

让 Agent 读懂论文

按照配套 skill 提取作者、年份、内容、贡献与标签；每项关键信息都保留原文页码和依据。在“整理设置”中选择 Agent 或自定义 API，也可设置 Agent 失败后自动切换 API。

查看整理 skill ↗
03

搜索、阅读、建立联系

按研究方向、标签和年份筛选；打开卡片查看贡献、核对原文，并记录自己的阅读笔记。

目录内文件按内容哈希去重。首次导入保留根目录原件；后续从待整理区归档。未核实的信息会单独提示。
