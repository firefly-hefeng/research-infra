# 文献模块部署

线上网页、目录、PDF、管理页和写入接口共用平台的飞书验证。保留已有 `/papers/api/` 代理和 `/papers/` 静态目录，后端仅监听本机。旧名 [public-reading.nginx.inc](public-reading.nginx.inc) 仅补充管理页的静态路由，所有路径继承已有网关。更新前检查现网的精确匹配位置，避免旧配置另行开放 PDF 或目录。

阅读入口为 `/papers/`，整理入口为 `/papers/manage`。目录读取 `GET /papers/api/catalog`，按需读取允许的原件。导入标为 `restricted` 的资料保留题录和来源，下载接口返回 403。管理接口继续使用原有平台认证和服务端验证，分享目录链接不会附带登录信息。

部署前保存现行前后端、代理配置和一致的 SQLite 备份，核实整理任务是否正在写入。新增导读表按论文内容哈希关联。依次验证飞书门禁、阅读目录、受限和可用原件、管理设置与笔记、桌面及手机端。静态目录和代码版本应匹配；需要恢复时优先还原代码和静态文件，保留部署后新增的笔记和导读。
