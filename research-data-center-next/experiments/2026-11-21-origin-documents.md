# 原点文档接入与权限验收记录

核对日期为 2026-11-21（Asia/Shanghai）。本次记录为科研基础设施验收，所讨论的研究方案、会议议题和样本规划按原件的证据级别引用。

## 输入与选择

核对了已登录成员可访问的「勿忘我百科」科研分支。「科研」首页说明整体规划、科研周会、科研探索库、数据相关、算法研究五个分支的用途，并要求文档注明维护人和修改日期。科研周会目录当时可见六次会议；11 月 14 日会议记录提出随后用平台日报和周报追踪进展。另核对了项目已有的四份飞书平台指南发布记录。

平台原有四个稳定入口，本次增加 26 个。目录覆盖知识库导航、团队路线、周会、问题与文献、数据规格、算法与评测及使用指南。重要长文包括语音智能研究资产手册、实验室落地方案、数据采集与建库规格书、五分钟语音认知筛查模块说明。目录收录周会总入口和两次可与平台归档对照的会议，其他场次从周会原生目录进入。其他知识库、私人未命名文件、个人病历、基因调控研究及源文档附件均未复制至目录。

证据入口：[团队科研知识库](https://wcn5kauqqbj1.feishu.cn/wiki/Md6wwmSJsi1CEhkgACWc3wYanvg) · [团队研究手册](https://wcn5kauqqbj1.feishu.cn/wiki/QSdfw3YXLinCqoktgTLcUT65nqd) · [科研周会](https://wcn5kauqqbj1.feishu.cn/wiki/CHpCw6POyiG5JFkWUGscuUmPnlh)。

## 查看与更新

27 个条目由飞书原生页面加载正文、表格和附件；三份平台自有 Markdown 从已登录门户的文档路径读取。飞书原件的修改随来源更新，新增子页随飞书目录更新。门户策展标题和短导读由负责人维护。索引和离线上下文只含门户已有导读、目录字段和源链接。

知识库首页表明空间为企业公开，科研根文档的分享面板显示组织内访问。使用成员自己的飞书会话决定是否可读。在浏览器接受嵌入时可站内阅读，拦截第三方会话或需要登录时可在飞书新窗口打开。仅门户主 HTML 的 `frame-src` 增加知识库租户固定来源，保留 `frame-ancestors 'none'`，阅读器仅嵌入经过验证的本租户标准 wiki 路径。飞书说明见[云文档的内容和权限](https://www.feishu.cn/hc/zh-CN/articles/803525191890-%E4%BA%91%E6%96%87%E6%A1%A3%E4%BB%8B%E7%BB%8D)。

## 方法与结果

- 使用真实飞书会话，先在与飞书不同源的测试页、随后在带正式策略的本机门户读取科研根文档。两次均取得原件正文，可核对五项分支与命名说明。门户未接收正文或源站会话凭据。
- 逐一打开 27 个飞书条目，均在本机门户内获得源站的可读文档或文件预览界面。长文及复杂预览采用有界抽读，未做附件逐个下载或全文逐字比对。另开全新浏览器会话直访科研根文档，飞书转到 `accounts.feishu.cn` 要求登录，没有显示科研知识库正文。[逐条验收记录](evidence/2026-11-21-origin-documents.json)
- 10 份原件有 12 个关联入口。两次周会分别回到 2026-W46、2026-W44 的成员时间表。研究资产手册、文献共享库及使用指南可返回相应科研模块。
- 专项浏览器回归使用临时测试目录和合成源响应。在 1440、390、320 像素验证桌面分组、手机选择器、旧原件 ID、返回上一页、源版本更新、来源拒绝、未知 ID、跨域来源拦截、长标题与完整 Markdown。三种宽度全部通过。测试源拒绝返回时，页面保留飞书原件入口，未读到先前的正文。
- 门户接口及 Agent 回归通过 19 项、45 个子断言；文档检查通过 243 个 HTML 和 1845 条现有内链。
- 既有首页团队进展和离线上下文下载回归分别在 1440、390、320 像素通过。
- 对真实登录页面作桌面及手机宽度目视验收。1440 与 390 像素视口的整页宽度分别为 1425 与 375 像素，原件均可读。手机目录收为可触控选择器。桌面与手机均保留在新窗口打开原件的入口。
- 发布材料由原点文档独立代码差异和目录合并器构成。合并器验证重复项及 ID 冲突，将新增条目写到新暂存文件，保留线上已有内容和原件地址。本地四条原目录合并后，30 个条目的内容及顺序与工作区一致。

## 正式发布后验收

2026-11-21 12:42（北京时间），用成员自己的飞书会话验收线上目录。启用前逐篇在正式门户域的受限阅读框内访问了 27 份飞书原件，均从对应源地址读到正文或文件预览。正式启用后，桌面（1440 像素）从目录进入研究资产手册；手机视口（390 像素）从选择器进入既有「分层指标」地址。两处均显示可读原文，测得阅读框宽度分别为 771 和 311 像素，页面没有横向溢出。两端均可在飞书另开同一份原件。[线上原点文档](https://rmp.wuwangwo.top/#documents)

三份平台自有原文各自在门户中展开，将显示的全部字符与其成员可读的 Markdown 比较，平台指南、议会规则和 Agent 手册三份均完全相同。用无会话的独立请求访问门户目录及议会原文均得到 401，直访飞书原件由源站转到飞书登录页。这里只确认本次成员权限和未登录行为，附件下载能力及其他成员的权限仍由具体原件决定。版本、检验值及两端读数见[验收数据](evidence/2026-11-21-origin-documents.json)。
