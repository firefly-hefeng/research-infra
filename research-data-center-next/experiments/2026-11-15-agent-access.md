# RMP-ELN-20261115-AGENT-ACCESS

日期：2026-11-15，Asia/Shanghai。记录者：Codex。类型：伙伴反馈驱动的 Agent 接入与文档工程验证。

## 输入与复现

伙伴在 `/#agent` 被 Agent 要求提供只读 token，但无法找到领取入口。实际核查：门户后端未启用 `--token-file`，外层 Nginx 经飞书会话校验；认证服务存在登录、回调、会话检查、退出等路由，没有 token 签发路由。旧 manifest 无条件描述 Bearer，前端又把内层令牌关闭称为开发模式，与公网登录边界不符。旧入库协议只覆盖资料接收，不能替代全平台说明。

进度和文献接口另有自己的写入行为；旧进度指南仍描述仅 Markdown、正文不开放。门户来源文献索引也不等于独立论文库。此次以代码、已登录读取和实际服务参数核对能力，不把规划 OpenAPI 当作已实现端点。

## 实施与验证条件

建立总手册、模块速查、建设现状、机器合同与维护约定，模块 AGENTS/README 链接同一入口。旧指南及专题链接保留，明确历史和适用范围。修正 manifest/OpenAPI 的可选目录鉴权描述，保留原鉴权实现。生产只替换已核对的两个描述函数与两处调用，不用整份本地服务覆盖线上其他修改。

登录成员可通过固定白名单 GET 下载研究上下文：9 个研究来源，加手册和机器合同。逐项保留时间、成功与失败；认证页、HTML 或登录失败阻止导出，普通部分失败如实标记。导出不读取账号配置、Cookie 或本地存储，不包含原始 PDF、数据集、权重和日报附件，不运行模型或写入报告。只读客户端可从实际文件读取来源，不把失败当空结果。

验收条件：已登录完整导出、部分失败、无权限及过期会话、键盘与窄屏操作、离线读取、未登录仍受保护；当前文书、原有 ID、原件与生产配置保留。

Windows 正式 `tests/` 范围为 145 passed、100 skipped、551 subtests passed；跳过项涉及 POSIX 能力，未宣称在 Windows 验证。首次不限定目录的收集误纳入 var/ 历史 Linux 工具并因 fcntl 失败，改用正式 tests/ 后通过。新增客户端接入与失败语义用例 4 项通过。门户首页回归、上下文正常/部分失败/认证 HTML/重定向/全失败/恢复、凭据哨兵和纯 GET 白名单在 1440、390、320 px 与双倍字号合成检查通过。243 个 HTML、1845 条内链检查通过。

线上首次真实导出为 3,255,674 字节，11 项来源均成功，离线客户端读取研究全景第 3 版、DeepSeek V4 Pro / Max，状态 ready。导出观察包含 229 条目录登记、298 条混合来源资料展示、336 条论文、5 个方向和4份文书；这些计数范围不同，不能相加作为独立资源数。未登录的 manifest 返回 401；已登录 manifest 为 1.3，明确没有个人 token 签发，内层 catalog_token_enabled 为 false。
