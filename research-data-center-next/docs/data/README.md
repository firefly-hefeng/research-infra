# 数据与模型

先选数据、模型或飞书台账，再按一级标签 → 研究大类 → 细分类浏览，也可以搜索名称或标签。飞书原记录保留来源、申请进度和使用条件，服务器条目链接原资料卡及登记 ID。

从[资料参考](/#literature)可以查找资料卡关联的论文、官方说明和项目页面，并回到关联资料。团队论文题录、收藏和笔记见[文献管理](/papers/)。

## 新增或补充资料

- 飞书「一级标签」描述首要研究用途，原视图自动按选项顺序排序。「空间音频」收录空间理解或定位，「语音情绪」收录情绪表达，「语音健康」收录通过言语、嗓音或访谈研究健康状况的资料。「生理声学」涵盖以心音、肺音、呼吸和咳嗽为主的研究。「通用语音与语言」收录跨方向语料、模型和索引，内容不明确时选「待核对」。研究大类与细分类继续提供下一级主题。
- 简介用两三句说明采集内容或模型能力、可研究的问题和实际限制。有正式项目页或论文就附链接；只有目录说明时照实写。
- 文件数、录音数、人数分别注明。遇到目录集合、历史缓存、特征或评测，写出资料角色。
- 如需交付文件，原有 `incoming/<用户名>/<提交名>` 可继续使用。放入文件和短 README，写清来源、内容、使用条件及联系人。一般说明和链接可以直接维护。

## Agent 读取顺序

1. `GET /api/platform/library` 返回 `themes`、`categories` 和 `items`。在 `items` 中按 `kind`、`theme_id`、`category_id`、`subcategory_id` 本地筛选，先读 `summary` 与 `usage_note`。服务端搜索底层目录用 `/api/assets?q=…&kind=…`。
2. `source` 区分服务器目录和飞书记录。`sources` 提供来源、更新时间及展示模式。飞书条目使用原记录 ID，服务器条目使用原资产 ID。版本及登记证据可从 `api_url`、`detail_url` 或 `source_url` 查阅。
3. 引用数量时一起核对 `count_label` 的单位和 `count_observed_at` 的来源时间。`observed_at` 记录飞书台账读取或服务器目录核对时间。准备读取或共享时，核对来源许可、适用人员与文件访问方式。
