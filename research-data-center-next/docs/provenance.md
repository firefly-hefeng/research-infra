## 已完成与限制

- 台账中的公共条目与本次发现的公共集合共同构成目录。精确数量见 `/api/summary` 与 `data/build-report.json`。条目可能是目录、集合或派生工件，不能当作独立数据集数量。
- 公共区全覆盖是整理范围；当前完成的是台账导入、入口核验与有深度限制的目录发现，不是所有文件内容扫描。未细分的深层资源通过父集合入口定位。
- 管理员盘点后，独立以 rmp 身份检查入口读取与遍历权限。`verified` 只说明入口存在且该账户可读；不证明所有子文件、内容、标签或许可证已经验证。`restricted` 的公共条目仍登记，不自动变更权限或提供内容下载。
- 公共区范围、数据用途、来源许可与当前账户权限分别表达。任何“公开”“公共”标签都不是外发授权。
- 目录发现最多 3 层，模型识别最多 5 层；单目录最多 10,000 个入口，总预算 20,000 个目录 / 120 秒。外部执行另设 150 秒硬上限。模型仅读取有限配置及文件元数据，不加载权重、不执行代码；数据记录不打开，不解压、不计算全盘哈希或 du。
- 历史数量保留原台账的快照日期。本次只更新路径状态，未将历史样本量冒充实时重算结果。未知为空，真实零值保留 0。
- 目录大小、音频大小、数据库逻辑大小及文件计数有不同口径；父子目录、压缩包与解压结果、同源副本不可直接相加，首页不展示这些数值的总和。
- 新发现且没有台账说明的条目明确标为目录发现，大小和样本量未知。模型权重存在不代表能加载、运行或复现。

## 更新流程

维护公共路径清单 → 低优先级运行 `tools/collect_metadata.py` → `tools/build_catalog.py` 生成公共导入文档 → 审阅 `data/build-report.json` → 用 `catalog.py import` 事务替换 SQLite 快照。保留上一个数据库快照供回滚，更新失败不覆盖在线目录。采集不修改数据源，HTTP API 只查询元数据。

发布包只包括公共筛选来源；构建和打包必须校验公共边界。原 `asset_id` 对应来源入口，不是不可变科研版本 UUID。本轮另建持久登记表 `data/resource-registry.json`，按 `asset_id` 保留 UUID 绑定；它仍表示登记条目，逻辑身份待确认，不因同一路径、相似名称就合并。

`tools/build_inventory.py` 从同一快照生成完整资源映射、逐条 HTML / Markdown 说明卡、资料分组与缺项。`catalog_generated_at` 和 `catalog_sha256` 指向输入快照；`generated_at` 是清册生成时间，不能当作重新观察服务器的时间。本轮不重新扫描数据内容、不写入原目录、不变更文件权限。说明中保留台账、程序观察与候选关系的证据类型；未知许可、维护人、样本单位或版本不由 Agent 推断填入。

正式规范和未来增补流程见 [规范中心](standards.html)，本轮逐条结果见 [资源清册](resource-inventory.html)。

## 研究说明与新人导览（2026-10-19）

研究说明通过 `data/annotations/talkbank.json` 和 `data/annotations/local-and-models.json` 逐条登记：简述、背景、适用研究、入门步骤、模态、语言及官方链接。精确来源、证据适用范围与审阅日期列在各卡片；建议的研究用途是导览建议，不是已完成的实验结论。

- `official_match`：本地条目可对应具体官方语料或模型介绍；仍不证明本地副本完整或与最新版本一致。
- `family_context`：仅用于解释所属库、工具家族或方法背景，未将该背景扩大为本地样本事实。
- `local_evidence`：说明来自本条台账、目录核验或有限 README；没有可靠上游匹配时保留这一状态。

本轮另对 221 个已登记公共位置下的固定 README / 说明卡文件名进行有限只读检查：每文件最多 64 KiB、总文本预算 2 MiB、60 秒预算，以低优先级运行。取得 10 份 README，未递归扫描、读取样本、加载模型或执行文档中的指令。读取时间为 `2026-10-18T22:45:46.374949+00:00`；所用说明的公共路径与内容哈希单列在条目的 `evidence_basis`。原目录权限与存在性快照没有因此更新。原始探查文本仅保存在开发/应用的 `var` 中，不进入发布包或下载接口。

说明文件的哈希、审阅日和记录覆盖数独立保存于映射来源中，便于追溯后续编辑。许可、维护人、逻辑身份、发布版本与内容完整性仍逐项保留，不因补齐阅读说明而自动确认。

`data/research-guide.json` 将 228 条登记记录分配到六个主要研究方向，每条恰好出现一次。分类计数来自映射中的明确成员；八条共享对象位置的特征保持独立。研究分类用于找资料，不表示已确认的数据血缘或实验可比性。
