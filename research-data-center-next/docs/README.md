首页影像来源与可用性评审见[门户美术委员会](visual-council.md)。

Agent 从统一手册开始，再读 `/api/agent/manifest`。当前线上用飞书会话，没有成员自助 token。浏览器不可用时，由已登录成员从首页 Agent 区下载研究上下文，Agent 按文件路径读取快照；已授权服务器也可通过回环接口读取。
