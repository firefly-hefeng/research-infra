# 刷新飞书数据台账

门户的「飞书台账」来自“公司数据与申请台账”。它展示数据名称、一级标签、研究大类、细分类和当前进度，并附原表入口。仓库带有注明读取日期的快照。自动刷新使用飞书自建应用，按原记录 ID 更新展示。

1. 给自建应用开通多维表格查看权限，在该多维表格添加应用协作者。按飞书文档用知识库节点查询取得多维表格的 `obj_token`。API 使用这个 Base token。
2. 在运行环境配置 `RMP_FEISHU_APP_ID`、`RMP_FEISHU_APP_SECRET`、`RMP_FEISHU_BASE_TOKEN`。建议使用仅服务账号可读的环境文件。
3. 调用 `python tools/sync_feishu_library.py --state-dir <门户配置的状态目录>`。校验返回记录数和时间，再由现有调度器定时运行。门户下一次读取即可使用新快照。

刷新失败时继续使用上一次成功的快照。简介按飞书记录 ID 和标题匹配，新条目出现后可补简介。门户读取上述五列；已有四列缓存可按细分类显示一级标签。飞书原表权限由原文档管理。
