# 科研进度平台使用指南

每天留下可接续的记录，每周梳理研究进展。打开 [科研进度平台](/progress/)，可提交日报、周报，阅读团队汇总和知识库；[日报入口](/progress/#daily)可直接打开当天记录。

## 1. 首次填写姓名后加入

在页面上方填写姓名，点击“加入成员”，随后在报告中选择自己的登记。已有姓名无需重复登记；同名同学请加组别等区分信息，不选择他人的登记。系统会创建独立归档目录，后续继续使用同一成员。

页面目前无需密码；姓名用于归档，不代表身份验证。提交前核对所选成员，不上传受试者身份信息、账号密钥或不适合团队共享的内容。

## 2. 日报记录过程，周报梳理进展

日报选择日期，填写“今日完成、结果与证据、问题与阻塞、明日计划”；日期默认采用团队时区。周报选择周次，填写“本周完成、结果与证据、问题与阻塞、下周计划”。

四栏均需填写，未知写“未说明”。写清数据版本、实验条件、指标来源和产物位置，区分观察、判断和计划，保留负结果。日报单独保存，**不会自动生成周报**；每周自行整理记录，再提交周报供团队汇总。

## 3. 在线填写或上传 Markdown

可以直接填写网页，也可下载所选成员、日期或周次对应的模板，填写后上传 UTF-8 `.md` 文件。标题和四个栏目须保留，单份上限 64 KiB，以页面提示为准。

以提交结果为准：相同内容重复提交不会重复保存；同一成员、同一天或同一周已有不同内容时不能覆盖，需联系维护人员更正。网页没有草稿自动保存，请保留本地副本。

## 4. 阅读团队进展与知识库

“团队进度”展示已发布的每周汇总；没有报告表示尚未发布，不代表没有开展工作，也不证明自动汇总任务已经运行。汇总仍只读取周报。

“团队知识库”提供入门、周报写作和实验记录说明，由维护人员更新。个人原始报告不通过网页公开浏览；周报中的内容可能进入团队总结。平台用于交流进展，不替代原始实验日志和正式数据说明。
