# 科研进度平台使用指南

本页保留旧入口。日常说明以[团队方向与成员进展](/docs/progress/README.md)为准；登录、Agent 接入与调用示例见[统一手册](/docs/agent-guide.md)。打开[团队进展](/progress/#team)、[写日报](/progress/#daily)或[交周报](/progress/#upload)。

<a id="section-1"></a>
## 1. 登录后核对登记姓名

通过统一门户登录后使用进度模块，已有姓名继续使用原登记。姓名与成员 ID 用于归档，不代表逐人身份验证；提交前核对本人登记。

<a id="section-2"></a>
## 2. 日报记录过程，周报梳理阶段

报告保留完成、结果与证据、问题与阻塞、下一步四栏。写明数据版本、评估范围和产物位置，未知写“未说明”。日报不会自动生成个人周报。

<a id="section-3"></a>
## 3. 在线填写或上传文件

日报支持 Markdown、TXT、CSV、Word、Excel、PowerPoint 或有文本的 PDF，一个正文可附最多 8 个附件，总量以上传提示为准。周报可上传一个已有文件。相同内容重复提交不会重复保存；不同内容不能覆盖，需由维护人员更正并保留原件。请保留本地副本。

<a id="section-4"></a>
## 4. 按个人时间表读全文和原件

周报与日报各自选择时间和成员，互不切换日期范围。启用团队共享后，登录成员可互查正文、原件与附件；点击有记录的周次或日期即可阅读。没有归档不代表没有开展研究。

研究全景整理近期共享报告和方向文书，附来源摘录、生成时间及更新状态；方向的既有基线单独保留。平台不替代原始实验日志，完整说明见[进度 README](/docs/progress/README.md)。
