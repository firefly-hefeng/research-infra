## 文档的阅读顺序

1. [Agent 手册](agent-guide.md)：解决访问与任务起点。
2. [模块接口](agent-modules.md)及各模块短 README：查确切参数和操作边界。
3. [机器合同](agent-contract.json)与 `/api/agent/manifest`：供程序发现现有入口。
4. [维护约定](agent-maintenance.md)：查更新职责、触发条件与验证。

`agent-protocol.md` 是入库专题；`portal-history.md`、`acceptance.md`、`council-architecture.md` 和根目录中的历史方案为带时间的背景材料。旧版本中静态令牌、无需登录或未开放原件的描述不作为当前访问说明。规划中的 OpenAPI 和数据字段不是已经可调用的端点。

资料与数量会随同步和成员提交变化，实时规模以各接口的原始观察时间、范围和返回值为准，不把本表日期当作每份数据的新核验时间。
