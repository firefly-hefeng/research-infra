# 团队方向与成员进展

首页先看研究大局和全员卡片。[团队进展](/progress/#team)按“周报阶段进展 → 日报每日推进 → 研究全景 → 研究脉络”阅读，周报与日报各有独立入口。默认整理最近 28 天日报及相交周次的周报，旧方向文书作为独立基线。无记录的成员照常显示，没有依据对应既有方向的工作列为“待归类工作”。[提交日报](/progress/#daily) · [提交周报](/progress/#upload)

日报可在线填写或上传多种格式，一次可加多个附件。启用团队共享后，统一登录的成员可互查日报、周报和摘要所附原件。每分钟任务检查输入变化后调用 DeepSeek V4 Pro / Max，从研究问题、关键发现、共同瓶颈和验证优先级归纳全景，校验来源摘录后写入团队 JSON 与 Markdown，保留旧版；页面可见时每 30 秒更新。日报按日、周报按周的记录节律图可回查来源。失败保留上次成功结果，显示更新状态并重试。

方向发生实质变化时，改对应的短 README。周报里有方向链接、关键结果、阻塞或下一步就可以接入；日常协作以一条可查的更新为准。

周报与日报各有个人名单和时间表，分别选择时间和成员。点击有记录的周次或日期读全文、下载原件与附件；查历史周报时，日报保留自己的日期范围。阶段归档保留当时的成员周报摘要和来源校验，当前全员记录从个人时间表查阅。没有归档的日期不代表研究未推进。

Agent 从 `/progress/api/progress-digest` 读取同一份总览、来源和整理状态；从 `/progress/api/directions/{id}` 读方向原文、`/progress/api/team/activity?week=…` 查个人时间表与报告正文。查询某成员日报加 `member=…&date=…`，查询周报加 `member=…&report=weekly`。摘要及原文保留各自时间、比较对象和评估范围。原件使用接口返回的受登录保护链接。

登录与调用示例见[统一 Agent 手册](../agent-guide.md)和[模块速查](../agent-modules.md)。姓名和成员 ID 用于归档，不代替身份验证。日报不会自动生成个人周报，研究全景也不替代原始实验记录。

阶段复盘可进一步从实验室和研究问题展开到成员及逐字摘录。已部署新版进度模块并发布阶段版本时，研究全景返回 `has_lab_review: true`，完整报告在 `GET /progress/api/lab-review`。报告在页末列出实际读取范围，包括项目盘覆盖及排除情况。
