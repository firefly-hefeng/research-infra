# 门户美术委员会

美术席核对图文层级、配色和移动端重排，天文素材席核对影像出处和署名，可用性席核对跨模块导航、键盘焦点、表单和空状态。

首页使用哈勃影像和简短说明。导航、团队进展与常用入口能直接打开现有模块。采用近黑航天蓝、冷白与学院蓝，朱红仅作主操作和章节编号强调；白色阅读面、细分隔线、明确字号与留白形成层次，少用重复套卡。参考 [NASA](https://www.nasa.gov/) 的影像与标题层级、[MIT](https://www.mit.edu/) 的任务入口、[Nature](https://www.nature.com/) 的研究内容编排。

团队页按周报阶段、日报每日、研究全景、方向脉络排列。D3 可视化将每日和每周记录分开，使用真实报告日期与份数，提供原文入口和文字替代；研究结论继续保留来源、划分与证据范围。

公共颜色、字体、圆角、间距与跨模块导航由 `/platform-theme.css` 提供。门户内的数据、成果、文书和算力页，以及独立进度与文献服务，都沿用同一组颜色和组件形态。后两项在单独运行时有本地样式。检查按钮、搜索筛选、表格工具条、状态标签、卡片、对话框、键盘焦点和空状态时，同时覆盖桌面与手机。
