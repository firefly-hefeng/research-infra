# 周会复盘的三级阅读与证据核对

2026-11-21，北京时间。验证成员能否从实验室结论找到研究问题、引用该问题的署名报告和原件，同时保留项目盘材料原有的阅读范围。

## 输入与方法

| 输入 | 版本和范围 |
| --- | --- |
| 团队自动稿 | `team-auto-first-33-corrected.json`，30 份署名报告、3 份已核准共享的项目摘录。研究问题 12 个，成员 8 人。 |
| 限阅复盘 | [双机复盘取证记录](2026-11-21-two-server-review.md)所列的两份校订 JSON。235 条主机观测，合并为 193 份不同项目正文，覆盖 102 个按目录划分的项目。 |
| 署名口径 | 日报或周报的来源 ID、成员 ID 和原件链接。项目存放位置只用于找原件。 |

团队页与 JSON 在读取已有校订稿时重建关联。只有实验室判断和研究主题引用同一来源的同一段原文时，两者才互相可查。主题引用的日报与周报按成员归并；多段引文来自同一人时只列一次。项目文档不能单凭目录归属链接到成员。报告保留原件所列计划和复盘建议的区分。

限阅读本首页给出本期三项周会优先议题，每个研究问题和每位成员都有一段摘要。展开后可核查详细结果、限制、后续验证和原件。优先次序属于本次编辑判断；每项建议均指向具体的校订判断。编辑清单绑定内部原卷指纹，原卷变化时，构建程序要求重新核对。本机可直接打开[周会读本](../var/reviews/20261121-both-hosts/meeting-brief.html)，同目录保存[学术判断与取证记录](../var/reviews/20261121-both-hosts/meeting-evidence.md)及原卷。归档或转移内部副本时保留该相对目录关系。成员共享页面可直接在原平台飞书会话中阅读。

```sh
python experiments/meeting_brief.py var/reviews/20261121-both-hosts
```

## 实测

| 项目 | 结果 |
| --- | --- |
| 同段引文与署名 | 33 来源自动稿中，12 条实验室判断均能定位到至少一个研究问题，共 24 条判断至主题的联系。成员报告与主题之间有 14 条联系。同源异段、异源同文、只有项目目录三种情况均通过防误归属测试。关联数只描述阅读路径。 |
| 团队浏览器 | 真实稿在 Edge 的 1440、390、320 像素宽度下，均可键盘选择实验室判断的研究问题、转入本人，再查看原报告链接。每种宽度核对 57 个页内链接，缺失目标及整页水平溢出均为零。 |
| 限阅浏览器 | 最终版在三种宽度均可阅读 3 个周会议题、9 个研究问题入口、8 名成员。原卷的 78 条个人判断、84 条方向判断保留，另有共享冷盘 5 项资产判断及补查项目 6 组判断。核对 30 个不同署名原件地址、156 个原卷判断定位、24 个冷盘引文、62 个补查引文（49 段送审及 13 项复读定位）。键盘可从判断展开引用，页面无水平溢出。内部 ELN 的 164 个链接可解析。 |
| 服务测试 | Linux 下先通过进度服务全套 167 项，再针对手工导入清单补齐排除目录检查。含并行模块改动的最终复测 170 项全部通过。包括新旧版本、空来源、同段引文和错误归属、导入路径与正文分别带排除词、团队及内部材料共享范围。 |

## 使用边界

同日第二次在两机核对 8 人既有科研入口，每机探测 24 个目录，其中 17 个可读。101 的 156 条与 47 的 79 条观测按完整路径及正文指纹逐项比对，无增删或内容变更。此次扫描的未完成目录队列与目录列举失败均为零；不可读取的入口仍计入覆盖限制。

16:00（北京时间）另从两机核查同一共享冷盘。每机检查 8 个可读成员入口，得到相同的 28 组路径及正文指纹，与先前 193 份材料的正文指纹无交集。24 份为同一 README 的历史快照，4 份为现行 README。其中一项持续更新，盘点时正文指纹以 `a56e2683e024` 开头，读取现行内容时以 `efa357aed732` 开头，取证绑定后者。101 的 `/mnt/peer-data` 自动挂载探测超时，其业务可见性未知。已查范围是两个目标服务器的直属入口及共享冷盘。

101 用进度服务正式收件机制核对全部日期，8 人、30 份规范报告。对每份报告的稳定 ID 和规范正文 SHA-256 排序，再对序列计算 SHA-256，得到 `5c83b369adda153fbc78dc41f0dbe4725c9a9084f5cc505c2146e31afe6433de`。历史人工校审记录、旧版实际发布包、含 3 份摘录的自动稿均与线上指纹完全一致。此口径包含已规范归档的日报和周报；附件不是独立报告。既有材料继续使用校订稿。进度服务的四个运行文件和周报说明已由部署负责人更新。

四份现行冷盘文档新增 24 段逐字摘录。DeepSeek V4 Pro 的最高推理档返回 11 项初判，调用 1 次，服务商计量 9,112 个 token。逐条对照原件后，校订了单包读回条件、不同批次的排队与部分传输状态，以及权重迁移和训练恢复的归属。5 条资产判断、对应原句及校订说明只进入限阅周会读本和内部记录。此次复核未重跑研究实验，也未给成员新增署名业绩。

同轮在其他获准的项目入口获得 36 处观测，按正文归并为 12 份，与先前 193 份及冷盘 28 份的规范正文指纹均无交集。取 49 处有行号的摘录，使用同一模型和推理档审阅。服务商计量 11,482 个 token，返回 12 项初判。49 个模型引文均匹配，另做 13 处原件复读定位，核对端到端结果、诊断记数和实际评测分母。将历史复盘、本周工程验收和只有运行说明的材料分开。个人栏只引用能够核对署名的报告。这 12 份的结论与原文仅供内部研讨。

团队端已经核验 37 个来源的共享版。上表中的 33 来源是导航测试的固定回放版本。限阅读本则以 193 份先前已审项目材料、4 份冷盘现行说明、12 份补充文档及 30 份署名报告为依据；24 份历史快照只保留版本索引。
