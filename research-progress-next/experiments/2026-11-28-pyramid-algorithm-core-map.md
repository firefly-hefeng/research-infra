## 实施

阶段复盘新增“实验室核心结论 → 研究主题 → 成员证据”三级金字塔。第一级统计四栏判断总数，第二级统计主题数及结论至主题的同段引文联系数，第三级统计署名报告覆盖及主题至成员联系数。联系数只描述阅读路径。原四栏、逐条引文、人工稿/自动稿切换、原报告链接、主题与成员双向定位均沿用原实现；原生链接和 `details/summary` 继续提供键盘操作，打印时隐藏导读和导航、保留正文。

## 验证结果

- 对两个实现模块和两份目标测试执行 Python `compile`，对两份 HTML 模板执行 Jinja 解析，均通过。
- 只读脚本核对 18 个真实 ID 在六类映射中各出现一次，未遗漏、未重复，方法总数为 39。
- Windows 直接运行目标 pytest 在收集阶段因缺少 `fcntl` 失败；WSL 有 Python 但没有 pytest。随后在 `experiments/.test-deps` 临时隔离安装 `tzdata==2026.6`，测试进程内以无操作 `flock` 和 `O_NOFOLLOW=0` 兼容顺序测试。最终 `tests/test_direction_methods.py`、`tests/test_lab_review.py`、`tests/test_lab_review_json.py` 共 **32 passed, 2 deselected**。两项排除仅是需要 Windows 符号链接权限的既有扫描测试，实际错误为 `WinError 1314`；本轮没有改扫描或锁实现，上述结果不能替代 Linux 原生锁和符号链接测试。
- 使用本机 Playwright Chromium，以真实方向数据和既有复盘数据在内存中渲染首页、复盘和方向详情，不启动或访问服务器。三类页面分别在 1440、390、320 px 及 100% / 200% 根字号下检查，最终文档和主体均无水平溢出，主要卡片无越界。
- 首轮浏览器检查发现方向页顶部导航在 390 px、200% 根字号下将页面撑至 475 px。为顶部品牌区和导航增加换行，并允许正文在长英文标记处换行；随后重跑全部尺寸和字号组合通过。
- 核心地图浏览器断言为 6 类、18 个稳定 ID、39 项具体算法、0 个待归类。复盘全部页内链接目标存在；键盘 Enter 可进入核心结论并展开四栏；打印媒体下导读和导航隐藏。详情仍包含指标、比较条件、适用范围、相关报告署名和证据入口。
- 生成并实际查看方向页和复盘页的 1440 / 390 px 临时截图，未见文字遮挡、卡片越界或导读顺序混乱。临时截图、测试依赖和 pytest 临时目录在验收后清理，未写入冻结数据目录。
