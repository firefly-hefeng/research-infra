# RMP-ELN-20261115-MEMBER-TIMETABLE

## 问题与范围

日期：2026-11-15，Asia/Shanghai。记录者：Codex。类型：成员报告入口与全文阅读的工程验证。用户要求删除单列的提交名单和情况，在周报、日报下按个人名单列时间表，点击时间读取对应报告原件，并修复内容切边。本轮不改报告原文件、归属、研究方向或模型策略。

## 修复前观察

日报、周报除了内容列表，另设提交情况与覆盖列表，入口重复。报告预览在代码中按 180、95 字符截短。390 px 视口打开研究全景中靳驰骋 W44 周报依据后，长飞书链接使页面内容宽度达到 452 px；来源未展开时，单测只检查页面整体宽度，未覆盖此问题。

[修复前原件指纹与复现条件](evidence/2026-11-15-member-timetable-before.json)保留何锋 11-14 日报的五个文件指纹，以及 DeepSeek Pro / Max 第 2 版摘要指纹。原日报、正文原件及两个附件均已存在。

## 方案与事先验收条件

周报、日报独立筛选，姓名下面列时间。周报显示所选周与此前三周，日报显示所选周的七天；有归档记录的时间可点击，无记录日期淡显并向读屏说明。点击后定位完整正文，正文下保留原件与附件。预览保留完整首段或首个连续编号项，以展开提示说明后续内容。展开后直接阅读四栏，移除重复预览；连续编号事项只在显示时分段，保留全部文字与标点。长链接、引用、附件名自然换行，避免用隐藏溢出掩盖内容。

| 场景 | 验收条件 |
| --- | --- |
| 人员入口 | 周报、日报各保留全员姓名与时间，删除单独提交情况列表 |

读取接口的 `weekly_timetable` 只补充四周记录入口，历史条目不批量读取正文；继续复用既有详情与受统一登录保护的原件接口。人工与 Agent 使用同一组稳定成员、周次和日期 ID。

## 验证结果

读取层 141 项测试通过；门户接口 10 项与 6 个子测试通过；243 份 HTML 的 1,841 个内部链接检查通过。报告阅读、研究全景、登录恢复和首页进展的浏览器回归覆盖 1440、390、320 px。主报告与全部展开的摘要来源另以 200% 字号检查可见元素的内部宽度，包含长正文、无断词 URL 和长附件名；并验证原链接、焦点、折叠、草稿、附件和提交身份隔离。

线上登录后核对：周报、日报下各有四名成员及时间表；何锋 11-14 日报、陆梓健 W45 和靳驰骋 W44 周报可点击读取。日报正文原件、两个附件和两份周报原件下载均为 HTTP 200，未登录的日报原件请求返回 401。何锋的五个归档文件与既有 Pro / Max 第 2 版研究全景 JSON 指纹均保持不变，未触发重新归纳。

实际验收追加发现两个问题并修复：阶段归档周次按钮在手机放大时内部溢出 4 px，改为自然换行；另一栏未变化时，时间链接可能保留旧周次，原因是链接优先读取旧状态且刷新比较未计入跨栏上下文。修复后回归包含两种 120 ms 慢接口顺序，线上也实际点击确认：周报切 W46 后点日报 11-14，周报仍为 W46；日报切 W45 后点 W44 周报，日报仍为 W45 且成员筛选保持。

真实陆梓健周报以“本周完成：1）…2）…”连续书写，编号之间没有空白。显示层先识别精确栏目前缀，再核对从 1 开始的连续编号及空白或中文句末边界，仅增添段落；样本数量、小数及 URL 不按此规则拆分。线上核对原字段 613 字符呈现为四段，忽略新增空白后与原字段逐字一致；收起预览完整保留首项 95 字符，未使用固定字数截断。

线上在三个宽度分别测试 100% 与 200% 字号（根字号 16 / 32 px），完整展开报告、归档和所有摘要来源后，没有内部横向溢出。390 px 视口内容宽度从修复前 452 px 恢复到 375 px，余下为滚动条；320 px 对应 305 px。[修复前](evidence/2026-11-15-report-source-before-390.png)与[修复后](evidence/2026-11-15-report-source-after-390.png)截图保留同一段来源的换行情况。

[最终结果、文件指纹与交叉点击证据](evidence/2026-11-15-member-timetable-after.json)记录具体数值。主发布的回退副本在服务器 `/var/backups/rmp-member-timetable-20261115-v1`；线上验收后两次仅更新阅读脚本，副本为同前缀 `v2`、`v3`。服务与两个既有定时器均为 active。部署未修改飞书源表、权限、报告文件、模型配置或其他模块。
