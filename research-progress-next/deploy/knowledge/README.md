# 日报、周报与方向更新

从个人时间表查日报、周报和原件，从研究全景看研究问题、发现、瓶颈和下一步。统一门户的日常说明见[进度 README](/docs/progress/README.md)，登录与 Agent 接入见[统一手册](/docs/agent-guide.md)和[模块速查](/docs/agent-modules.md)。独立部署的接口说明见项目 README。

## 成员提交与阅读

周会沿用「本周完成、结果与证据、问题与阻塞、下周计划」四栏，各方向重点讲与上周相比改变了什么判断。会前提交一次，会上围绕需要共同决定的问题展开，会后在原实验记录补上决定和下一次验证。见本页的《一份可接续的科研周报》。

- 日报可在线填写，或上传 Markdown、TXT、CSV、Word、Excel、PowerPoint、有文本的 PDF；一个正文可附最多 8 个附件，总量以上传提示为准。
- 周报可上传一个已有文件，写实际工作、结果与证据、阻塞和下一步；涉及具体方向时带上方向名或链接。日报不会自动生成个人周报。
- 含数据、模型或指标的结论注明版本、划分与使用范围。没有新结论，可以写验证到哪里。姓名和成员 ID 用于归档，提交前核对本人登记。
- 周报与日报各自选择时间和成员。统一门户启用团队共享后，登录成员可互查新旧报告正文、原件与附件；有原件时提供原件，否则提供归档 Markdown。只提交适合团队共享的内容。
- 相同内容重复提交不重复保存；不同内容不能覆盖，需要更正时联系维护人员保留旧原件。阶段归档保留当时的成员摘要与来源，当前全员记录从个人时间表查阅。

## 方向维护与自动整理

维护团队 `directions/` 中对应的 Markdown，保留同一文件名作为方向 ID。首行写方向名称，可选核对日期和负责人；正文按「研究问题」「当前进展」「下一步」「来源与范围」整理。已有报告用链接关联，旧基线不当作本期新成果。

启用研究全景后，现有收件任务检查近 28 天共享日报、相交周次的周报和方向文书，内容变化才重新整理。摘要附来源摘录，失败保留上一版并显示状态。进展模型不接收日报附件或周报原始二进制文件，也不启动分析、训练或服务器任务。

## Agent 读取

通过门户访问时使用 `/progress/api/public` 查成员和限制，`/progress/api/team/activity?week=…` 查个人时间表与正文，`/progress/api/progress-digest` 查研究全景与更新状态。方向为 `/progress/api/directions` 和 `/progress/api/directions/{id}`；周归档为 `/progress/api/team` 和 `/progress/api/team/{周次}`。原件沿用接口返回的链接。独立进度服务去掉 `/progress` 前缀。
