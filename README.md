# 科研管理平台

平台汇集资料、论文、团队进展和服务器资源。日常从[科研工作台](https://rmp.wuwangwo.top/)进入。

| 我要做什么 | 从哪里开始 |
| --- | --- |
| 让 Agent 接手、核对当前建设情况 | [Agent 使用手册](research-data-center-next/docs/agent-guide.md) · [建设现状](research-data-center-next/docs/agent-status.md) |
| 找数据、特征、模型和飞书台账 | [数据与模型](research-data-center-next/docs/data/README.md) |
| 看方向和成员进展，提交日报或周报 | [科研进度](research-progress-next/README.md) |
| 查论文、原文依据和整理方式 | [文献管理](paper-library-next/README.md) |
| 查算力、读重要文书、维护门户 | [科研资源门户](research-data-center-next/README.md) |
| 约定研究协作和评审方式 | [基础学术委员会](research-data-center-next/docs/research-council.md) |
| 把研究问题、输入、文献和实验记录串起来 | [科研基础设施联合评审](research-data-center-next/docs/research-infrastructure.md) |

方向成员用一份短 README 维护研究问题、联系人、最新证据和下一步。成员和 Agent 共用这些说明。需要原始依据时沿资料 ID、周报、实验和文献链接查找。

门户、科研进度和文献应用各自运行，可独立更新。按各模块 README 启动和检查。旧版 `research-data-center/`、历史部署与方案记录可从相应目录查阅。研究原件及运行状态由各服务维护。
